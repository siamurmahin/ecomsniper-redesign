# Source copy

Their live pages, captured verbatim, with the date. The pages in this rebuild
are written from these files rather than from a fresh scrape each time, so
there is one record of what the copy actually said and when.

Captured from `https://ecomsniper.io` on **3 September 2026**.

Their site renders client-side, so the served HTML is an empty `#root` and
`curl` returns nothing useful. Everything here was read out of a real browser
after scrolling the whole page, because content mounts on reveal.

Headings arrive with the spaces stripped — `WEKNOWWHATITTOOKTOEARNTHISMONEY.`
— because their headline animation splits words into per-letter spans. The
spacing is restored by hand in these files.

**These are a source, not an authority.** Anything making a factual or legal
claim about the business needs the client to confirm it is current before it
ships. Mismatches against the copy already in `src/content/` are listed in
`../TODO.md`.
